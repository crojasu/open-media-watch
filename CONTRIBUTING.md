# Contributing

Open Media Watch is at an early stage and maintained by one person, so reviews can be slow.

- **Issues are welcome**: bug reports, questions, and ideas for monitoring other topics.
- **Pull requests**: please open an issue first so we can agree on the change before you write code.
- Run the tests before sending anything: `pip install -r requirements-dev.txt && pytest`.
- Do not commit credentials, databases, or real personal data (names of real victims, suspects or any private individual) in code, tests or fixtures. Use clearly fictitious data.
